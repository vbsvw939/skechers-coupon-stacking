Two structural rules matter just as much. Skechers accepts **one code per order**, so you can't combine the PICKUP code with a newsletter code — pick whichever saves more. Keeping a clean cart of regular-priced, code-eligible items gets you the cleanest result — which is also why starting from an empty cart matters.
